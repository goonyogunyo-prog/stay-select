GitHubの全blob path/SHA一覧と累積ZIPのGit blob SHA manifestを照合し、GitHubにしかないファイルや衝突を可視化します。比較だけであり、GitHubへの書き込み・ファイル削除・自動マージはしません。

1. GitHub側の全blob一覧

GitHub API recursive treeのblobを path,sha 2列CSV、または SHA1 path 形式で貼り付けてください。省略・truncatedの一覧は安全な完全照合には使えません。
